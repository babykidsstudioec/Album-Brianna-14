# Álbum Brianna · 14 Years of You

Sitio de Momentos Digitales SP. Álbum interactivo 3D con fotografías y música.

## Cómo publicarlo en GitHub Pages

1. En la cuenta `babykidsstudioec`, crea un repositorio **público** nuevo llamado exactamente `Album-Brianna-14`.
2. Sube **el contenido de esta carpeta** al nivel principal del repositorio: `index.html`, `app.js`, `config.js`, `styles.css`, `assets/`, `.nojekyll`.
3. En el repositorio, abre **Settings → Pages**.
4. En `Build and deployment`, selecciona **Deploy from a branch**, luego `main`, carpeta `/(root)` y guarda.
5. Cuando se publique, el enlace será:
   https://babykidsstudioec.github.io/Album-Brianna-14/

## Vista previa de WhatsApp

La página contiene etiquetas `og:image`, `og:url` y `twitter:card` con una imagen pública 1200 x 630 en `assets/portada-whatsapp.jpg`.
Se deben publicar el HTML y la imagen en la dirección indicada para que WhatsApp pueda obtenerla.
Si se cambia el nombre del repositorio o la cuenta, actualiza `og:image`, `og:url`, `twitter:image` y `canonical` de `index.html`.
Puede ser necesario esperar la propagación de GitHub Pages y que WhatsApp actualice su caché.

**Privacidad:** GitHub Pages publica estos recuerdos de manera pública. No es un álbum privado protegido por contraseña.
